# カレンダー（Android アプリ）

スマホ向けのシンプルな予定管理アプリです。予定はスマホの中だけに保存され、アプリを閉じていても予定の前に通知が届きます。

## できること

- 月表示・週表示の切り替え（週表示は時間軸つき、空いている時間をタップするとその時刻で予定を追加）
- 予定の追加・編集・削除（タイトル、場所、終日、開始・終了、色 8 色、通知、メモ）
  - 開始・終了の時刻はそれぞれ「×」で「時刻なし」にできます（例: 19:00〜、〜12:00、日付だけ）
  - 開始時刻がない予定の通知は、終日と同じく「当日／前日 ＋ 時刻」で決めます
- 通知（アプリを閉じていても届く普通の通知。スマホを再起動しても予約は残ります）
  - 時間のある予定: なし／開始時／5分前／10分前／15分前／30分前／1時間前／1日前
  - 終日の予定: なし／当日／前日 ＋ 好きな時刻
- 日本の祝日の表示（祝日名つき）
- キーワード検索（タイトル・場所・メモ）
- 設定: 週の始まり（日曜／月曜）、祝日の表示、新しい予定の通知の初期値
- バックアップの書き出し・読み込み

## スマホへのインストール

1. スマホのブラウザでリポジトリの **Releases** にある「カレンダー 最新版」を開きます
   （`https://github.com/nosuke3190-lab/study-planner/releases/tag/calendar-app-latest`）
2. `calendar.apk` をタップしてダウンロードします
3. ダウンロードしたファイルを開きます。初回は「提供元不明のアプリ」の許可を求められるので、使っているブラウザ（Chrome など）に許可してください
4. 「インストール」をタップします
5. 初めて開いたときに通知の許可を聞かれるので「許可」を選んでください

アップデートするときも同じ手順で新しい `calendar.apk` を入れるだけです（予定は消えません）。

### 通知が遅れる・届かないとき

- スマホの「設定」→「アプリ」→「カレンダー」→「通知」がオンになっているか確認してください
- Xiaomi・OPPO・vivo などは電池の節約機能が強く、通知が止められることがあります。
  「設定」→「アプリ」→「カレンダー」→「バッテリー」で「制限なし」（または「最適化しない」）にしてください

## 開発

```bash
npm install
npm run dev            # ブラウザで画面を確認（通知はアプリ版のみ）
npm run android:sync   # ビルドして Android プロジェクトへ反映
```

`calendar-app/` 以下を変更してプッシュすると、GitHub Actions（`.github/workflows/calendar-app-android.yml`）が APK をビルドし、Releases の `calendar-app-latest` に置き直します。

- 画面: React + TypeScript + Vite
- Android 化・通知: Capacitor（`@capacitor/local-notifications`）
- 保存: `@capacitor/preferences`（スマホ内）
- 祝日: `@holiday-jp/holiday_jp`
